# 慢慢停 · 第一人稱路邊停車

**坐進駕駛座，用後視鏡與車內視線練習路邊停車。**

預設就是第一人稱。看左右後視鏡確認車身與路緣的相對位置，轉頭觀察，控制方向盤、油門與煞車，把車慢慢倒進去。繁體中文、免帳號、無時間限制。

**[開始練習](https://ntustray.github.io/parallel-parking-lab/)** · [測試與截圖](https://github.com/ntustRay/parallel-parking-lab/actions)

![第一人稱駕駛座與三面後視鏡，由 GitHub Actions Chromium 擷取](https://ntustray.github.io/parallel-parking-lab/screenshots/driver.png)

## 第一人稱是主角

- **預設駕駛座**：實際坐在左駕位置，觀察前車、路緣與車頭。
- **左右＋中央後視鏡**：三個獨立攝影機視點，隨車輛位置與轉角即時更新；測驗模式也能使用。
- **調整練習視野**：65° / 80° / 95°，可切換左右後視鏡的路緣觀察角度。
- **轉頭觀察**：拖曳擋風玻璃；J / L 按住看左／右，K 回到正前方，也提供觸控按鈕。
- **先看示範，再自己練**：示範保留第一人稱，可對照後視鏡與方向盤動作。
- 俯視與跟車視角保留作為理解幾何的輔助。

## 已實作

- 自製 Canvas 3D renderer：街道、路緣、建築、樹木、車輛與轉動的前輪。
- Rear-axle bicycle model，4.5 × 1.8 m 車身、2.7 m 軸距、最大 35° 前輪轉角。
- P / R / D、低速油門、煞車優先、停穩才可換檔、持續方向盤轉角。
- 四種視角：斜俯視、正上方、跟車、駕駛座。
- 三種車位長度、左右側停車、練習／測驗模式。
- 即時教練、倒車預測軌跡、路緣距離、角度、碰撞及前後修正計數。
- SAT 車身碰撞；四角入位、車身角度 < 8° 且停穩才通過。
- 依碰撞、修正與位置評分；最近 50 次結果保存在 localStorage。
- 桌機及觸控操作；失去焦點與觸控取消時會放開踏板。

## 操作

| 操作 | 鍵盤 |
| --- | --- |
| 方向盤 | ← → / A D；放開後保留轉角 |
| 回正 | X |
| 油門 | ↑ / W |
| 煞車 | Space / ↓ / S |
| 前進／倒車 | 停穩後 Q，或按 P / R / D |
| 看左／右 | 按住 J / L，放開回正 |
| 看正前方 | K；或按畫面中的視線按鈕 |
| 自由轉頭 | 拖曳擋風玻璃 |
| 換視角 | C |
| 重新練習 | R |
| 顯示／隱藏軌跡 | H |

主要練習請維持第一人稱，先觀察後視鏡，再慢慢操作。需要釐清車身旋轉方式時，可暫時切換俯視，再回到駕駛座。練習目標是車身四角在框內、與路緣平行、完全停穩。

## 本機執行

需要 Node.js 22+。遊戲沒有 runtime dependencies，不需要 npm install。

```sh
npm start
# http://127.0.0.1:4173
npm test
npm run build # 產生 _site/，可交給任意靜態主機
```

瀏覽器 E2E：

```sh
npm install --no-save --package-lock=false @playwright/test@1.56.1
npx playwright install chromium
npx playwright test
```

GitHub Actions 會執行物理測試、Chromium E2E，對正式 build 進行測試，擷取四種視角及手機畫面，保存 HTML report、失敗 trace 和截圖；測試成功後才部署 GitHub Pages。Repository Settings → Pages → Source 設為 GitHub Actions。
