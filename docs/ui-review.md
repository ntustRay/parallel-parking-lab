## 操作與評分

- 排 R 後 S／↓ 可倒退，W／↑ 與畫面踏板也可沿目前檔位行駛；Space 一律煞車優先。D／P 時 S／↓ 為煞車。
- R 鍵直接選倒車，Backspace 重新練習，Q 切換 D／R。停穩後才可換檔。
- 練習評分不再只在通過時才給分：位置 55、平行 25、路緣 20。前六次方向修正不扣分；碰撞每次扣四分、最多十六分，額外修正最多扣六分。
- 練習模式允許 12 cm 標線餘裕、車身角度小於 12°，仍需停穩；測驗保留嚴格四角入位、小於 8° 與原本的碰撞／修正扣分。
- 分數與通過條件分開，避免得到部分分數卻被誤認為已完成入位。

## 驗證與下一步

最後版本本機驗證：16 項 Node 測試、25 項 Chromium E2E 全通過。Node 測試涵蓋物理、碰撞、完整入位、輸入優先序與評分；Playwright 涵蓋四視角、三面鏡、倒車、煞車、焦點、示範、設定保存及六種螢幕尺寸。正式 build 使用內容 hash，CI 通過後才部署並更新公開截圖。

後續優先：實玩回饋、可調鏡面倍率與方向、個人軌跡重播，以及更細緻的車內與街景模型。
