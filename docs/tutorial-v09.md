# v0.9.0：觀察式路邊停車教學

這輪以第一人稱教學和比例為主，補齊中段回正直退，保留既有踏板與回正規則。E2E、unit test 維持停用。

## 影片核對

參考：[藍鯨・路邊停車原理分析](https://www.youtube.com/watch?v=uikA64IpoPM)。本輪以 Browser 查看畫面文字及模型示意，確認三個關鍵觀察階段：

| 畫面時間 | 觀察與操作 | 遊戲中的對應 |
| --- | --- | --- |
| 約 2:29 | 前車車尾通過後側三角窗後，朝路緣轉向 | 步驟一、二；按住觀察可轉向後側窗 |
| 約 3:16 | 外側鏡能看清後車兩個頭燈後，回正並繼續直退 | 步驟三；真正有一段前輪為零的直線倒退 |
| 約 4:31 | 路緣側鏡接近前車尾燈的位置後，向外反打收車頭 | 步驟四；另提醒前車角及路緣距離 |
| 收尾 | 車身接近平行後回正，煞停、微調 | 步驟五 |

右側停車的外側鏡是左鏡，路緣側鏡是右鏡；左側場景相反。沒有把固定 45°／50° 當作反打口訣。

**適用範圍：**影片車型、駕駛座和本遊戲不同。內裝的窗框、座椅眼點與鏡角是示意值，未做實車視線標定。示範路線由本車幾何和碰撞限制規劃；不宣稱已精準識別影片中的三角窗、頭燈或尾燈觸發位置。玩家需練習觀察距離，不能把提示視為任何車型都通用的固定線。

## 本輪修正

- 原示範省略了中段直退；現在有五個實際操作階段，每一幀記錄階段與踏板。
- 原教練反打提示比示範晚約 1.4 秒，回正提示卻在方向盤仍打滿時出現；現在使用示範同一個階段。
- 原示範有踩油門／煞車，畫面卻顯示鬆煞車蠕行；現在踏板燈號與狀態同步。
- 示範可暫停並觀察；暫停時不接受修改方向盤或換檔。觀察按鈕放開、失焦或取消時會解除；鍵盤觀察不再同時踩煞車。
- 補上左右後側小窗細柱，滑鼠可轉向後方；按住觀察會跟隨教學步驟更新視線及鏡面標示。
- 預測線使用完整車寬、車尾位置，從目前真實後角接出；固定轉角預測明確移除舊轉向目標。
- 側鏡相機移出實體鏡殼後側；俯視時關閉遮擋車格的倒車畫面，倒車畫面也移除造成模糊的背景濾鏡。

## 實際檢查

未新增或執行 E2E／unit test。使用語法與 build、離線單檔 build、一次性數值探索及實際瀏覽器截圖檢視。

數值探索以真正 step 積分並逐幀檢查碰撞：寬鬆／標準、左右四種情境可規劃入位，總長約 17 秒。回正直退階段全程轉角為零；標準格的該段約 0.36 m，寬鬆格約 1.36 m。最終均停穩 P 檔、在嚴格車格內；示範不記入玩家成績。寬鬆示範途中最近路緣約 16 cm，接近警示仍會如實顯示。

[18 張步驟圖庫](https://ntustray.github.io/parallel-parking-lab/screenshots/)包含五階段的車內／俯視對照、三角窗、鏡面、評分及手機。截圖只記錄畫面，不做圖片 diff 或測試斷言，也不阻擋部署。
